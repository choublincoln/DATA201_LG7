# =========================================================
# STEP 3: API KEY AND .env CONFIGURATION
# =========================================================
#
# Deliverable 5 uses the DataFinder API to retrieve
# geographic area information for Airbnb listings.
#
# An API key is required for the API lookup script to work.
#
# 1. Obtain a DataFinder API key from the relevant
#    DataFinder service. https://koordinates.com/ by creating an account
#
# 2. Create a file named ".env" in the project root folder
#    (DATA201_LG7-1/), if it does not already exist.
#
# 3. Add your API key to the .env file using this format:
#
#   DATAFINDER_API_KEY=your_api_key_here
#
# Replace "your_api_key_here" with your actual API key.
# Do not include quotation marks unless required by the
# API configuration.
#
# 4. Save the .env file.
#
# 5. Make sure the Python API script loads the key from
#    the .env file using the appropriate environment
#    variable name: DATAFINDER_API_KEY.
#
# 6. Install the required Python packages if they are
#    missing from your Python environment.
#
# The API script uses the DataFinder API to look up
# geographic area information for Airbnb listings.
#
# IMPORTANT:
# - Do not upload or commit your .env file to GitHub.
# - Make sure ".env" is listed in .gitignore.
# - Never share your API key publicly.
# - Each group member should configure their own API key
#   if they need to run the API lookup.
# - API requests may be subject to rate limits.
#   Avoid repeatedly forcing the API script to run.
#
